# Netflix Insights

An end-to-end data analytics project exploring Netflix's content library with SQL, Python, and Power BI.

## Project overview

This project explores trends in content type, genres, release patterns, ratings, and country-wise distribution. It uses SQL for querying, Python for data analysis, and Power BI for interactive visualization.

## Tools

| Tool | Purpose |
| --- | --- |
| SQL | Data exploration and querying |
| Python | Data analysis |
| Jupyter Notebook | Interactive analysis |
| Power BI | Interactive dashboards and reporting |

## Project files

| File | Description |
| --- | --- |
| `netflix_titles (1).csv` | Netflix titles dataset |
| `netflix.project.ipynb` | Python analysis notebook |
| `netflix_sql_project.sql` | SQL queries and analysis |
| `netflix.Bi.project.pbix` | Power BI report |
| `Netflix.power.poin_report.pptx` | PowerPoint report |

## Getting started

### Requirements

- Python
- Jupyter Notebook
- pandas, matplotlib, and seaborn
- Power BI Desktop (to open the `.pbix` report)

Install the Python packages:

```bash
pip install pandas matplotlib seaborn jupyter
```

### Explore the notebook

Start Jupyter Notebook in the project directory and open `netflix.project.ipynb`.

### Run the SQL analysis

Open `netflix_sql_project.sql` in a SQL client and run the queries against the dataset.

### View the reports

Open `netflix.Bi.project.pbix` in Power BI Desktop, or view the included PowerPoint and PDF reports.

## Dataset

- **Source:** [Kaggle — Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **Records:** Approximately 8,800 titles
- **Fields:** Title, type, director, cast, country, date added, release year, rating, duration, genre, and description
